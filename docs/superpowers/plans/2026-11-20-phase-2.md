# Phase 2 "Ba hòn đảo" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Contract v1.1: standardized numbers, Nights 2–3, dash, charm, drifters, wind, falling, pause and a 3-night browser campaign, with deterministic headless output.

**Architecture:** Extend the existing `Game` class. Map data lives in `nights.ts`, pure terrain queries in `terrain.ts`, contract values in `tuning.ts`. Every tick follows PHASE-2's 12-step order. Renderer builds a new world per night and drives the same core.

**Tech Stack:** TypeScript, Three.js, Vite, esbuild, Vitest, Playwright (shots only).

**Spec:** `docs/superpowers/specs/2026-11-20-phase-2-design.md` + `docs/phase/PHASE-2.md`

## Global Constraints

- 60 ticks/s, `DT = 1/60`; metres and seconds; Y up.
- `src/core/**` imports no DOM, Three.js or Node API.
- Same seed + scenario + inputs produce byte-identical JSONL.
- Positions rounded to 3 decimals; score integer; event tick ≥ 1.
- Scenario/inputs format errors exit 2 on stderr; CLI errors exit 1.
- Balance numbers only from `src/core/tuning.ts`; `game.contract.json` must deep-equal `TUNING`.
- Night durations: 300 / 330 / 360 s. Flames 3 each night.
- Palette values from PHASE-2 §3.8 verbatim.
- Headless full night ≤ 30 s.

## Review Focus

- Player under a tier-2 lantern must not deposit through the floor (`interact` 3D test).
- Walking into a tier wall must not teleport up (terrain step test).
- Dash must not make the player invulnerable or freeze gravity beyond 12 ticks (dash tests).
- Pause must freeze `sim_tick`, time, cooldowns and spawns but keep incrementing `tick` (pause test).
- Dropped motes must expire after 480 ticks and not respawn forever (TTL test).
